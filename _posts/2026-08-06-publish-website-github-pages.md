# كيف تنشر موقعك مجاناً على GitHub Pages؟

ما تحتاج تدفع فلوس استضافة عشان تنشر موقع شخصي أو مدونة. GitHub Pages يستضيف موقعك مجاناً بالكامل — وهذا الموقع اللي تقرأ فيه الآن مبني بنفس الطريقة بالضبط.

![رسم يوضح رفع ملفات من جهازك لـ GitHub ثم نشرها كموقع مباشر]({{ '/assets/images/github-pages-demo.svg' | relative_url }})

<div class="key-point" markdown="1">
GitHub Pages مناسب للمواقع الثابتة (مدونة، معرض أعمال، موقع شخصي) — مو لمواقع تحتاج قاعدة بيانات أو تسجيل دخول مستخدمين.
</div>

## الخطوة 1: أنشئ مستودع بالاسم الصحيح

بحسابك على GitHub، أنشئ مستودع جديد. فيه نوعين من المواقع:

- **موقع مستخدم رئيسي**: اسم المستودع لازم يكون بالضبط `اسم-حسابك.github.io` — والموقع يطلع على `https://اسم-حسابك.github.io`
- **موقع مشروع فرعي**: أي اسم ثاني تختاره — والموقع يطلع على `https://اسم-حسابك.github.io/اسم-المستودع/`

## الخطوة 2: ارفع ملفات موقعك

ارفع ملفات HTML وCSS وJS لمشروعك للمستودع (بنفس طريقة رفع أي مشروع — راجع مقالنا عن حفظ المشاريع على GitHub لو محتاج تفاصيل).

## الخطوة 3: فعّل GitHub Pages من الإعدادات

من صفحة المستودع، روح لـ **Settings → Pages**، واختر الفرع (Branch) اللي فيه ملفاتك (غالباً `main`)، واضغط حفظ. خلال دقيقة أو دقيقتين، موقعك يصير مباشر على الإنترنت.

<div class="key-point" markdown="1">
لو موقعك موقع "مشروع فرعي" (مو مستخدم رئيسي)، تأكد إن كل روابطك الداخلية (CSS، الصور، الروابط) تحسب المسار الفرعي صح، وإلا راح تطلع مكسورة.
</div>

## لو موقعك مبني بـ Jekyll (مثل هذا الموقع)

Jekyll يخلي كتابة مقالات جديدة أسهل بكثير من كتابة صفحة HTML كاملة كل مرة:

- ملفات القالب العام تروح بمجلد `_layouts`
- كل مقالة جديدة تروح بمجلد `_posts` بصيغة اسم `YYYY-MM-DD-عنوان-المقال.md`
- إعدادات الموقع العامة تكون بملف `_config.yml` بجذر المستودع

GitHub Pages يبني موقع Jekyll تلقائياً بمجرد ما ترفع الملفات — ما تحتاج تثبت أي شي إضافي.

## مشاكل شائعة أول مرة

- **الموقع يطلع بدون تنسيق (بدون CSS)**: غالباً مشكلة مسار — تأكد إن روابط ملف الـ CSS تستخدم المسار الصحيح حسب نوع موقعك (رئيسي أو فرعي).
- **مقالة جديدة ما تظهر**: تأكد إن تاريخها مو "بالمستقبل" بالنسبة لوقت بناء الموقع الفعلي، أو فعّل `future: true` بملف `_config.yml`.
- **تعديل رفعته بس ما يبين بالموقع**: انتظر دقيقة للبناء، وسوّي تحديث قسري بالمتصفح (Ctrl+Shift+R) لتفادي أي نسخة قديمة محفوظة بذاكرة المتصفح.

## الخلاصة

نشر موقع مجاني عبر GitHub Pages يحتاج بس: مستودع بالاسم الصحيح، رفع الملفات، وتفعيل الخيار من الإعدادات. باقي التفاصيل (قوالب، مقالات متعددة، تصنيفات) تقدر تضيفها تدريجياً بعدين — بالضبط الطريقة اللي كبر فيها هذا الموقع نفسه.
