# كيف تنشر أي موقع مجاناً على GitHub Pages؟

ما تحتاج تدفع فلوس استضافة عشان موقعك يكون على الإنترنت. GitHub Pages يستضيف أي موقع ثابت (Static Website) مجاناً بالكامل — سواء كان صفحة تعريف بسيطة، معرض أعمال، موقع شركة صغيرة، أو حتى صفحة واحدة فقط.

<div class="key-point" markdown="1">
GitHub Pages مناسب لأي موقع "ثابت" (ملفات HTML/CSS/JS جاهزة تُعرض كما هي) — مو لمواقع تحتاج قاعدة بيانات حية أو تسجيل دخول مستخدمين وتخزين بياناتهم.
</div>

## شنو تحتاج بالضبط؟

بس شيئين: حساب مجاني على GitHub، وملفات موقعك جاهزة (حتى لو ملف `index.html` واحد بس). هذا يكفي تماماً.

## الخطوة 1: أنشئ مستودع (Repository)

من حسابك على GitHub، اضغط "New Repository" وأعطه اسم. فيه نوعين من المواقع حسب الاسم اللي تختاره:

- **موقع مستخدم رئيسي**: اسم المستودع لازم يكون بالضبط `اسم-حسابك.github.io` — والموقع يطلع مباشرة على `https://اسم-حسابك.github.io`
- **موقع مشروع فرعي**: أي اسم ثاني تختاره — والموقع يطلع على `https://اسم-حسابك.github.io/اسم-المستودع/`

كلاهما مجاني وبنفس الإمكانيات، الفرق بس بشكل الرابط النهائي.

## الخطوة 2: ارفع ملفات موقعك

ارفع ملفاتك للمستودع — أبسط طريقة هي السحب والإفلات مباشرة من صفحة المستودع على GitHub بالمتصفح (زر "Add file → Upload files")، أو عبر Git لو مرتاح فيه أكثر (راجع مقالنا عن حفظ المشاريع على GitHub لو تبي التفاصيل). المهم إنك تتأكد من وجود ملف اسمه بالضبط `index.html` بجذر المستودع — هذا هو الملف اللي يفتح تلقائياً لما حد يزور موقعك.

## الخطوة 3: فعّل GitHub Pages من الإعدادات

من صفحة المستودع، روح لـ **Settings → Pages**، واختر الفرع (Branch) اللي فيه ملفاتك (غالباً `main`)، واضغط حفظ. خلال دقيقة أو دقيقتين، موقعك يصير مباشر على الإنترنت برابط جاهز تقدر تشاركه فوراً.

<div class="key-point" markdown="1">
لو موقعك "مشروع فرعي" (مو مستخدم رئيسي)، تأكد إن روابط ملفات الـ CSS والصور بداخل موقعك تستخدم مسارات نسبية صحيحة، وإلا راح تطلع مكسورة بسبب اسم المستودع الإضافي بالرابط.
</div>

## هل موقعك يحتاج أدوات بناء إضافية؟

لو موقعك ملفات HTML/CSS/JS جاهزة (زي أغلب مواقع التعريف والمعارض الشخصية)، ما تحتاج أي شي إضافي — GitHub Pages يعرضها مباشرة كما هي.

لو موقعك يحتاج "يُبنى" أول (مثلاً مشروع React أو Vue)، لازم تبني نسخة الإنتاج النهائية على جهازك أول (أمر زي `npm run build`)، وترفع محتويات مجلد المخرجات الناتج (غالباً اسمه `build` أو `dist`) بدل الكود المصدري الخام.

**ملاحظة جانبية**: لو تبي مدونة فيها مقالات متعددة تُضاف بسهولة بدون كتابة صفحة HTML كاملة كل مرة، فيه أدوات مخصصة لهذا الغرض (أشهرها Jekyll، وهو المُستخدم فعلياً ببناء هذا الموقع نفسه) — بس هذا موضوع مقال منفصل، مو شرط أساسي لمجرد نشر موقع عادي.

## مشاكل شائعة أول مرة

- **الموقع يطلع بدون تنسيق (بدون CSS)**: غالباً مشكلة مسار — تأكد إن روابط ملف الـ CSS تستخدم المسار الصحيح حسب نوع موقعك (رئيسي أو فرعي).
- **الموقع يطلع فاضي أو 404**: تأكد إن اسم الملف الرئيسي بالضبط `index.html` (بحروف صغيرة) وموجود بجذر المستودع مباشرة، مو داخل مجلد فرعي.
- **تعديل رفعته بس ما يبين بالموقع**: انتظر دقيقة للبناء، وسوّي تحديث قسري بالمتصفح (Ctrl+Shift+R) لتفادي أي نسخة قديمة محفوظة بذاكرة المتصفح.

## الخلاصة

نشر أي موقع مجاني عبر GitHub Pages يحتاج ثلاث خطوات بس: مستودع بالاسم الصحيح، رفع ملف `index.html` (وملفاتك الثانية)، وتفعيل الخيار من الإعدادات. بعدها موقعك مباشر على الإنترنت مجاناً بالكامل، بدون أي فاتورة استضافة شهرية.
