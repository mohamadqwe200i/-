# كيف تحفظ مشاريعك على GitHub؟

لو مشروعك موجود بس على جهازك، وانطفى الجهاز أو انمسح الملف بالغلط، خسرت كل شي. GitHub يحل هذي المشكلة: نسخة من مشروعك محفوظة أونلاين، مع تاريخ كامل لكل تعديل سويته. خلنا نوصلك من الصفر.

<div class="key-point" markdown="1">
Git هو البرنامج اللي يتتبع تعديلاتك على جهازك. GitHub هو الموقع اللي يخزّن نسخة أونلاين من مشروعك. تحتاج الاثنين مع بعض.
</div>

![رسم تجريدي يمثل البرمجة وإدارة الأكواد]({{ '/assets/images/theme-code.svg' | relative_url }})

## الخطوة 1: ثبّت Git وأنشئ حساب

- حمّل Git من موقعه الرسمي (git-scm.com) وثبّته على جهازك.
- أنشئ حساب مجاني على github.com لو ما عندك وحد.

## الخطوة 2: جهّز مشروعك محلياً

افتح الطرفية (Terminal) بمجلد مشروعك واكتب:

```
git init
```

هذا يحوّل المجلد العادي إلى مجلد يتتبعه Git. تسويها مرة وحدة بس لكل مشروع جديد.

## الخطوة 3: احفظ أول نسخة (Commit)

```
git add .
git commit -m "أول نسخة من المشروع"
```

السطر الأول يقول لـ Git "تابع كل الملفات بهذا المجلد". السطر الثاني يحفظ لقطة (Snapshot) من حالة مشروعك الحالية، مع وصف قصير توضحه أنت.

<div class="key-point" markdown="1">
اكتب وصف Commit واضح ومفيد ("أضفت صفحة تسجيل الدخول" أفضل بكثير من "تعديلات"). راح تشكر نفسك بعد شهر لما تحاول تفهم شنو سويت.
</div>

## الخطوة 4: أنشئ مستودع (Repository) على GitHub

من موقع GitHub، اضغط "New Repository"، أعطه اسم، واختر إذا يكون عام (Public) أو خاص (Private).

## الخطوة 5: اربط مشروعك المحلي بالمستودع وارفعه

GitHub بيعطيك سطرين جاهزين بعد ما تنشئ المستودع، شبه كذا:

```
git remote add origin [رابط مستودعك]
git push -u origin main
```

بعد هذي الخطوة، مشروعك كامل صار محفوظ أونلاين على GitHub.

## كل مرة تسوي تعديل جديد

بعد أول رفعة، دورة عملك تصير بسيطة ومتكررة:

```
git add .
git commit -m "وصف التعديل الجديد"
git push
```

## غلطة شائعة تجنبها

<div class="key-point" markdown="1">
لا تنسى `git add .` قبل `git commit` — لو نسيتها، Git ما راح يحفظ تعديلاتك الجديدة، ويحفظ نفس النسخة القديمة بس.
</div>

## الخلاصة

Git وGitHub يبدون معقدين أول مرة، لكن فعلياً تحتاج تحفظ بس أربع أوامر: `init`، `add`، `commit`، و`push`. بعد أسبوع استخدام يومي، بتصير عملية تلقائية بدون ما تفكر فيها.
