## 4. إضافة مخطط بياني تفاعلي
لإضافة مخطط بياني تفاعلي، استخدم كتلة كود بلغة `chart` وضع بداخلها بيانات بصيغة JSON متوافقة مع مكتبة Chart.js — السكربت يحوّلها تلقائياً إلى رسم بياني حقيقي:

```chart
{
  "type": "bar",
  "data": {
    "labels": ["يناير", "فبراير", "مارس", "أبريل"],
    "datasets": [{
      "label": "عدد الزوار",
      "data": [120, 190, 300, 250],
      "backgroundColor": "#0984e3"
    }]
  }
}
```
