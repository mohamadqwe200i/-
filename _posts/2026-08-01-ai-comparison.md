
## 4. إضافة مخطط بياني تفاعلي
لإضافة مخطط بياني تفاعلي، استخدم كتلة كود بلغة `chart` وضع بداخلها بيانات بصيغة JSON متوافقة مع مكتبة Chart.js — السكربت يحوّلها تلقائياً إلى رسم بياني حقيقي. تقدر تضيف أكثر من مجموعة بيانات (dataset)، كل وحدة باسمها ولونها الخاص:

```chart
{
  "type": "bar",
  "data": {
    "labels": ["السرعة", "البرمجة", "الإبداع", "الدقة"],
    "datasets": [
      {
        "label": "ChatGPT",
        "data": [8, 7, 9, 8],
        "backgroundColor": "#0984e3"
      },
      {
        "label": "Gemini",
        "data": [9, 9, 7, 8],
        "backgroundColor": "#00b894"
      }
    ]
  },
  "options": {
    "plugins": {
      "title": { "display": true, "text": "مقارنة سريعة بين النموذجين (من 10)" }
    }
  }
}
```

## 6. أمثلة تنسيق نصوص إضافية
هذا القسم يوضّح كل عناصر تنسيق النص المتاحة تلقائياً في أي مقالة جديدة.

اقتباس مميّز يبرز فكرة مهمة:

> الذكاء الاصطناعي أداة تكمّل المطوّر ولا تلغيه — الفارق يصنعه من يعرف يوجّه الأداة الصح.

قائمة نقطية:
- دعم كامل للعربية والإنجليزية
- وضع ليلي ونهاري تلقائي
- مخططات بيانية تفاعلية

قائمة مرقّمة:
1. اكتب المحتوى بصيغة ماركداون عادية
2. أضف صور أو فيديو أو أكواد حسب الحاجة
3. احفظ ورفع الملف — الموقع يتكفّل بالباقي

وأخيراً، تقدر تشير لأمر برمجي داخل نص عادي مثل `npm install` أو تضيف [رابط خارجي](https://jekyllrb.com) بسهولة.
